# Personal Hub

Aplicación personal del propietario, independiente de empresas y proveedores. Versión del código: 1.2.0.
React/TypeScript/Vite y FastAPI/SQLAlchemy/Alembic/PostgreSQL. API /api/v1, MFA, Diario, Project/Tag y Tareas.
No contiene Activity Collector profesional ni requiere Azure DevOps. Calendario de eventos, alarmas y asistente siguen siendo futuros.
